# AGI Picture Workshop

Open `index.html` directly in a browser. It contains its own renderer and eight supplied room projects, so no server or installation is required. The optional reference image lives beside the game assets and loads from the project folder.

## Locked drawing rules

The picture is always **160×168 pixels**, and every drawing color comes from the fixed **16-color EGA palette**. Zoom changes only the display size. The drawing surface uses the game's corrected wide-pixel proportions. Reference images are display guides; they are never sampled into the picture or included in PNG exports.

Tools:

- **Line:** drag from start to end.
- **Outline:** click successive vertices; Enter or Finish shape commits the connected lines.
- **Filled shape:** click vertices; Enter closes the polygon, fills it with the pen color and draws a black outline.
- **Flood fill:** click an enclosed region to fill it. An opening in the outline lets the fill through, as in a picture editor.
- **Brush:** drag to draw with a 1-, 2- or 3-native-pixel brush.
- **Escape / Cancel stroke:** discard unfinished geometry.
- **Undo / Redo:** reversible edits; Ctrl/Cmd-Z and Ctrl/Cmd-Shift-Z also work.

Toggle **Reference** and its opacity slider to compare against the generated composition. Choose reference loads an image locally for that visit. Toggle **Grid** when placing individual pixels.

## Room projects

The Room selector opens the gallery, courtyard, shed, orchard, bridge, mill, grotto and belfry. Each has its own browser autosave and supplied drawing. Reopen room loads the selected room's original drawing. Changing rooms preserves that room's current autosave; exported JSON also records the room identity.

## Character scale guide

Toggle **Elara scale (40 px)** to show her actual 8×40 native walking cel over the drawing. Set Foot X / Y, or Alt-click the canvas to move her feet. This is a drawing ruler only; it is not exported into PNGs or painting commands.

The shed project uses a 40-pixel person against a work surface at y108 and bench feet at y129: 21 pixels of furniture height, rather than the previous oversized bench. Its removable tools, shelf, boards and barrel share that scale. Collision and interaction points were moved with the furniture.

## Editable commands

Select a command in the ordered list to inspect or edit its native coordinates, name and color. Apply edit commits the JSON. Move up/down changes painting order. Hide/show and Delete are undoable. Use pen color recolors the selected command.

The playback slider and Play drawing reveal commands in order. Show all restores the complete picture.

Save JSON downloads an editable project. Open JSON loads it. Export native PNG always exports the entire picture at 160×168, without the reference, grid, command-selection bounds or cursor. Browser autosave is independent of the game's save slots. Reopen room restores the selected supplied redraw; Undo can recover the prior working project.

## Drawing sources and build

`../assets/rooms/*-workshop-v1.json` are the editable room sources. `gallery-workshop-v1.json` is the approved gallery drawing. It contains a new 190-command redraw of `gallery-prompt-trial-v6b.png`; no source image pixels are copied. The shared renderer `agi-picture.js` is used by both the editor and the game asset builder for every supplied project.

The first authored redraw is generated by `../tools/draw-gallery-workshop.cjs`. Running that script again replaces the project with that initial drawing, so preserve edited JSON before using it.

The other seven source projects are generated by `../tools/draw-room-workshops.cjs`. It preserves existing projects unless explicitly given `--force`. That option regenerates those seven baseline drawings, so preserve edited JSON first.

To apply a downloaded project to its room:

1. Run `node tools/import-agi-picture.cjs /absolute/path/to/agi-picture.json` from the project root. The exported room identity selects its destination, and the old source receives a dated backup. For older JSON without room metadata, append the room name (for example `potting`) as a second argument; otherwise it defaults to gallery.
2. Run `node tools/trace-room-art.cjs` to render all eight room projects. This step requires sharp.
3. Run `node tools/build-expanded-adventure.cjs` to embed the new pictures in the standalone game.
4. Run `node tools/build-agi-editor.cjs` to refresh the editor's supplied projects.

Native effects and furniture depth overlays are in `../game/gallery-room.js`; interaction and collision coordinates are in `../assets/stolen-voice-map.json`. Moving major objects to new places requires updating those game coordinates too.

This is a browser drawing editor with AGI constraints. JSON exports are its own editable command format, not compiled interpreter picture resources.
